<h1>CV Web Interactif</h1>
CV personnel développé en HTML/CSS/PHP dans le cadre du cours de développement web en B1 à l'École Hexagone.
<h2>Description</h2>
Site web personnel présentant mon parcours, mes compétences linguistiques et mes centres d'intérêt. Le projet met l'accent sur une présentation visuelle soignée avec une palette de couleurs cohérente (noir/vert) et une navigation fluide via des ancres.
<h2>Technologies utilisées</h2>

<ul>
  <li>
    HTML5 - Structure sémantique    
  </li>
  <li>
    CSS3 - Styling et responsive design
  </li>
  <li>
    PHP - Modularité (header séparé)
  </li>
</ul>
<h2>Fonctionnalités</h2>

Navigation interne par ancres pour accès rapide aux sections<br>
Design responsive avec media queries pour tablettes/mobiles<br>
Header modulaire réutilisable (PHP include)<br>
Mise en page Flexbox pour un affichage adaptatif<br>
Tableau HTML pour la présentation des compétences linguistiques<br>

<h2>Structure du projet</h2>
cv-web/
├── cv.html           # Version HTML statique
├── cv.php            # Version PHP avec header modulaire
├── header.php        # En-tête réutilisable
├── cv.css            # Feuille de styles
├── count.php         # Script de comptage de caractères
└── Image CV.jpg      # Photo de profil

<h2>Points techniques</h2>
<h3>Design responsive</h3>

Adaptation du layout pour écrans < 768px<br>
Réorganisation de la disposition header/menu en mobile<br>
Utilisation de Flexbox pour la mise en page<br>

<h3>Accessibilité</h3>

Balises sémantiques HTML5<br>
Navigation par liens d'ancrage<br>
Contraste de couleurs adapté<br>

<h3>Modularité</h3>

Séparation du header en fichier PHP externe<br>
Facilite la maintenance et les mises à jour<br>

<h3>Compétences démontrées</h3>

Structuration HTML sémantique
Mise en page CSS avancée (Flexbox)
Design responsive avec media queries
Bases de PHP (include, manipulation de fichiers)
Gestion de projet web simple
