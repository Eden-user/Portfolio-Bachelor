<h1>Magellan</h1>
Application tablette développée pour la Compagnie de la Lanterne Magique dans le cadre de leur projet spectacle/livre/exposition sur Magellan.<br>
<h2>Contexte</h2><br>
La Compagnie de la Lanterne Magique a créé un spectacle, un livre et une exposition sur le voyage de Magellan. Ce projet consiste à développer une application tablette interactive pour accompagner ces créations culturelles, avec une carte interactive et une version digitale du livre.<br>
Ce projet est réalisé dans le cadre de ma micro-entreprise de développement web. Une collaboration future est prévue pour la création d'un site web pour l'association.<br>
<h2>Technologies</h2><br>
<ul>
  <li>
    HTML / CSS / JavaScript
  </li>
  <li>
    Turn.js pour l'effet de feuilletage
  </li>
  <li>
    SVG pour la carte interactive (possibilité de l'imprimer et la projetter à grande échelle sans perte de qualité)
  </li>
  <li>
    Application web fonctionnant hors ligne sur une ancienne tablette Android
  </li>
</ul>

<h2>
  Développement
</h2>
<h3>
  Étape 1 - Carte SVG personnalisée
</h3><br>
Création d'une carte interactive en SVG représentant le voyage de Magellan, adaptée pour le spectacle et l'exposition.<br>
<h3>
Étape 2 - Application de feuilletage  
</h3><br>
Développement d'une application tablette avec système de feuilletage (Turn.js) permettant de parcourir le livre en version digitale. L'application fonctionne entièrement hors ligne sur une ancienne tablette Android.
<h3>Étape 3 - Intégration carte et livre (en cours) </h3><br>
Intégration de la carte SVG dans l'application avec des points d'intérêt cliquables sur le trajet de Magellan. Un clic sur un landmark ouvre le livre au chapitre correspondant. Développement de fonctionnalités supplémentaires : jeux interactifs, navigation par chapitres, galerie photos du spectacle.
